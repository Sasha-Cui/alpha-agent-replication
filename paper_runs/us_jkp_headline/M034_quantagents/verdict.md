# M034: QuantAgents common-task verdict

Status: **closed—not evaluable as a monthly U.S./JKP strategy because the proposed policy is architectural pseudocode rather than an identified trading rule**.

The original paper's headline object is the complete system: Emily analyzes markets, Bob tests strategies, Dave controls risk, and manager Otto chooses actions using weekly meetings, three memory stores, simulated trading, and an adaptive blend of simulated and real rewards. The paper names GPT-4o-2024-05-13, 26 tools, 60 indicators, top-10 memory retrieval, a NASDAQ-100 universe, and a 2010-2020/2021-2023 split. Original-paper pages covering the agents, risk and dual-reward equations, input/model/result table, and appendix tools were text-checked and visually inspected.

The linked author repository remains a static site. A live 2026-09-04 UTC check confirms the same 2024 head, seven commits, one branch, and zero tags, releases, or forks. Its rendered algorithms, profiles, meeting videos, and 90 paper-table duplicates are useful documentation, but there is no system code, data, prompt execution, memory state, strategy pool, action log, order/fill path, or return array. The printed risk score omits all four weights and component normalization; the strategy pool has no finite grammar or realized members; the dual-reward equations omit the learned policy and reward history.

The old JKP momentum/quality/liquidity/low-risk score is rejected because it is a researcher-selected narrative translation, not QuantAgents. Filling the pseudocode, using a current replacement model, or promoting a baseline would likewise define a new strategy.

No monthly return is assigned. This does **not** show that QuantAgents's reported positive results are false or that the method loses to JKP; the disclosed system cannot generate an attributed common-task portfolio. The prior audit retains 0/238 numeric cells and 0/14 empirical panels regenerated and flags action-count, volatility, dataset, live-date, and annual-return-equation conflicts.
