# M015: MACI v1/v2 common-task verdict

Status: **closed—not evaluable as a monthly U.S./JKP strategy despite substantial recovered training evidence**.

The title in this milestone corresponds to arXiv v1/v2: a four-expert, fine-tuned GPT-4o system that combines cross-sectional coin/image and market/news probabilities into weekly top-quintile, linear-probability, and market-weighted portfolios over the CoinGecko top 30. ArXiv v3 is a different 2025 experiment and is not substituted.

The source-history recovery is strong: 962 historical fine-tuning messages and all 930 distinct referenced images survive, and the source-specified 961-record upload file is reconstructed exactly. The native fine-tuning method issues the expected file and GPT-4o job-create calls under an in-memory stub. But those payloads were committed after v2, the paper’s real file/job IDs and active checkpoint are absent, and the source’s multi-agent fine-tuning blocks are commented. Required prices, blockchain factors, market/news inputs, weekly universes, checkpoints, inference records, predictions, holdings, costs, and portfolio arrays are unavailable.

Training a new model would create a different policy. Synthetic blockchain data, arbitrary scores passed through released portfolio functions, the incompatible v3 system, or a generic JKP mapping would not preserve the v1/v2 strategy. No substitute receives a return.

MACI reports positive crypto performance, but 0 of 321 table units and 0 of 21 plotted units is regenerated from released inputs. These claims remain unresolved—not demonstrated false and not shown merely to underperform JKP.

M015 is closed without a return. M016, MarketSenseAI 2.0, is now active.
