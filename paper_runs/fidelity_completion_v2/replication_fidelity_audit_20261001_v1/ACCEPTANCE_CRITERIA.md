# Acceptance criteria for a faithful paper replication

These criteria are proposed for future native replication attempts. The matrix applies them conservatively to existing evidence; this audit runs no experiments. A finished bounded audit/experiment can have a negative result, an unresolved discrepancy or an unavailable input. That is separate from demonstrating every original-paper result.

1. **Identity and scope.** Pin the exact paper revision and target experiment, including its original market, period, task, scale, models, main comparisons and ablations. Inventory numerical tables, quantitative figure series and substantive prose claims. Native tasks excluded from our common monthly U.S./JKP exercise still require native assessment. Keep revised-paper targets separate from earlier versions.
2. **Inputs and mechanism.** Bind attributable implementation or a fully specified independent implementation, data snapshot, universe/calendar, model/checkpoint/tokenizer, prompts, state, parameters, search/selection and execution rules. Record unavailable objects. Replacements and reconstructed choices receive an explicit adapted scope. Original response logs can support exact historical replay; a new faithful stochastic replication instead needs the prescribed mechanism/model, data and repeat protocol, with a predeclared comparison criterion.
3. **Execution evidence.** Preserve actual native executions, failures, unfinished trials, raw intermediate/final outputs, request/seed identities and environment/config lineage. Code presence, document rebuilds, fixture tests and replay of our own cached records each establish their own limited result.
4. **Published-result comparison.** Recompute the identified published outputs using the original method. Deterministic quantities must match reported precision or a justified numerical tolerance. For stochastic experiments, specify the original repetition/aggregation scheme and an outcome-independent acceptance criterion before new outcomes. Classify exact agreements, discrepancies, partial coverage and data-gated calculations separately. Never infer whole-paper success from a subset or a favorable adapted economic result.
5. **Independent checks and limitations.** Check information dates, generation/evaluation boundaries, factor/model reuse, financial accounting where applicable, metric definitions, costs where applicable, uncertainty and result-generation lineage. Leave unresolved conflicts visible. Independent human review is a separate external status; assistant QA cannot fulfill it.
6. **Effort measurement.** Start and end a native attempt explicitly. Record execution, debugging, audit work, eligible queue wait, dependency/hold wait and packaging separately. Retain failed attempts. Allocation wall time includes network/API/I/O waits; summed concurrent allocations do not measure labor or elapsed calendar time. Missing hours stay unavailable. Time to faithful replication remains unavailable until that event is established.

Full-paper certification requires a complete target inventory and no unexplained missing targets or substitutions. A more limited reproducible component or adapted native experiment should be certified at that named scope. Availability checks are dated observations, not proof that a missing artifact can never be recovered.
