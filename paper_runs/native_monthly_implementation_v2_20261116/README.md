## Provenance and privacy

This package reads saved source, replay, account and attribution outputs; it does
not rerun them. Source-state equality, scheduler success and economic output
hashes were checked. Its verification manifest binds aggregate exports. Security
identifiers and held values from screening failures are omitted; exact witnesses,
inputs, holdings and replies remain in the authorized private workspace.

The older [v1 audit](../native_monthly_study_v1_20261116/REPORT.md) is preserved as
historical evidence, not the current admission rule. No frozen file was rewritten.
