# Vendored ACM article template

- Package: `acmart`
- Production release: 2.19
- Release date: 2026-06-27
- Source: <https://ctan.org/pkg/acmart>
- Retrieved: 2026-08-08

The ICAIF 2026 call requires the latest ACM article template and the
`sigconf` two-column format with the `anonymous` parameter. The included
`acmart.cls` was generated without modification from the included
`acmart.dtx` and `acmart.ins`. `ACM-Reference-Format.bst` is the bibliography
style distributed with the same production release.
